# Frontend rules

Read the rules that apply to what you are about to write.

| Read this | When you are |
|---|---|
| `.claude/rules/constants-rules.md` | using any enum, status, label, limit or `PERMISSIONS` value |
| `.claude/rules/api-call-rules.md` | calling the backend |
| `.claude/rules/page-rules.md` | adding a page or using its props |
| `.claude/rules/state-rules.md` | writing `useEffect`, loading state or alerts |
| `.claude/rules/list-rules.md` | rendering a list, or making one searchable or filterable |
| `.claude/rules/navigation-rules.md` | adding a page, detail view, tab, button or action |
| `.claude/rules/styling-rules.md` | writing any styling or layout |
| `.claude/rules/test-rules.md` | writing or changing Playwright tests |
